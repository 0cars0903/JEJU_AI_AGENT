# 심사용 계정 안내

평가 위원과 참가팀 평가자가 웹 데모의 Claude 기능(판단 과정 AI 설명, 전문가 모드)을 써 볼 수 있도록 계정을 안내한다.

> 이 파일은 저장소에 빈칸으로 둔다. 실제 아이디와 비밀번호는 최종 제출 ZIP의 이 파일에만 적는다.

## 1. 웹 데모
- 주소: https://jeju-agent-junhees-projects-5f5f2302.vercel.app
- 질문과 답, 동네 비교, 통계 기법, 보고서 인쇄는 로그인 없이 쓸 수 있다.
- Claude 기능(판단 과정 AI 설명, 전문가 모드)은 로그인해야 켜진다.

| 항목 | 값 |
|---|---|
| 아이디 | `<제출 ZIP에서 채움>` |
| 비밀번호 | `<제출 ZIP에서 채움>` |
| 사용 기간 | 평가 기간(2026-11-23 ~ 2026-11-27) |

### 로그인 방법
1. 화면 왼쪽 사이드바 맨 위의 [로그인]을 누른다. 폰에서는 머리말의 메뉴 단추로 사이드바를 연다.
2. 아이디와 비밀번호를 넣는다.
3. 사이드바의 '전문가 모드'를 열고, 분석을 문장으로 요청한다. 예: `43개 동네를 방문·매출·가게 수로 군집분석 해줘`

### 제한
- 전문가 모드는 하루 요청 수에 상한이 있다(서버 인스턴스마다 50건).
- 로그인은 한 IP에서 10분에 5번까지 틀릴 수 있다. 넘으면 10분 뒤 다시 시도한다.
- Claude 키에는 사용 한도가 걸려 있다. 한도에 닿으면 전문가 모드가 꺼지고, 질문과 답은 그대로 쓸 수 있다.
- 웹 데모는 Ollama가 없어 질문 해석에 사전 규칙(판정용 300문항 중 199, 66.3%)을 쓴다. 센터 PC 탑재본은 임베딩 분류기(248, 82.7%)를 쓴다(`tools/eval/m1_eval.py`).

## 2. 센터 PC 탑재본(ZIP)
- 질문과 답, 동네 비교, 통계 기법, 전문가 모드(로컬 모델 `qwen2.5:7b`)는 로그인 없이 쓴다.
- Claude 기능은 요청 단위로만 켠다. 담당자 계정(위 표의 아이디·비밀번호)으로 로그인한 뒤, 전문가 모드에서 [Claude로 분석]을 누른 요청에만 ZIP의 `.env`에 든 평가용 키를 쓴다. 평가용 키에는 사용 한도가 걸려 있고, 평가가 끝나면 폐기한다.
- 실행 방법은 `README.md` '빠른 실행'을 따른다.
