# 심사용 계정 안내

평가 위원과 참가팀 평가자가 GitHub에서 내려받아 실행한 제출본에서 Claude 기능(판단 과정 AI 설명, 상세 분석의 [Claude로 분석])을 써 볼 수 있도록 계정을 안내한다.

> 이 파일은 저장소에 빈칸으로 둔다. 실제 아이디와 비밀번호는 최종 제출 ZIP의 이 파일에만 적는다.

## 1. 실행
- 실행 방법은 `README.md` '빠른 실행'을 따른다(Ollama 설치 → 설치 스크립트 → 실행 스크립트).
- 질문과 답, 동네 비교, 통계 기법, 보고서 인쇄, 상세 분석(로컬 모델 `qwen2.5:7b`)은 로그인 없이 쓴다.
- Claude 기능은 담당자 계정으로 로그인한 뒤, 상세 분석에서 [Claude로 분석]을 누른 요청에만 쓴다. 이때 ZIP의 `.env`에 든 평가용 키를 쓴다. 평가용 키에는 사용 한도가 걸려 있고, 평가가 끝나면 폐기한다.

| 항목 | 값 |
|---|---|
| 아이디 | `<제출 ZIP에서 채움>` |
| 비밀번호 | `<제출 ZIP에서 채움>` |
| 사용 기간 | 평가 기간(2026-11-23 ~ 2026-11-27) |

## 2. 로그인 방법
1. 화면 왼쪽 사이드바 맨 위의 [로그인]을 누른다.
2. 아이디와 비밀번호를 넣는다.
3. 사이드바의 '상세 분석'을 열고, 분석을 문장으로 요청한 뒤 [Claude로 분석]을 누른다. 예: `43개 동네를 방문·매출·가게 수로 군집분석 해줘`

## 3. 제한
- 상세 분석은 하루 요청 수에 상한이 있다(기본 50건, `JEJU_EXPERT_DAILY`).
- 로그인은 한 IP에서 10분에 5번까지 틀릴 수 있다. 넘으면 10분 뒤 다시 시도한다.
- Claude 키에는 사용 한도가 걸려 있다. 한도에 닿으면 [Claude로 분석]이 꺼지고, 질문과 답·로컬 모델 상세 분석은 그대로 쓸 수 있다.
