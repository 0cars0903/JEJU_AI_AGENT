# 심사용 계정 안내

평가 위원과 참가팀 평가자가 GitHub에서 내려받아 실행한 제출본에서 Claude 기능(여러 단계 질문의 도구 고르기, 상세 분석의 [Claude로 분석])을 써 볼 수 있도록 계정을 안내한다.

> 이 파일은 저장소에 빈칸으로 둔다. 실제 아이디와 비밀번호는 최종 제출 ZIP의 이 파일에만 적는다.

## 1. 실행
- 실행 방법은 `README.md` '빠른 실행'을 따른다(Ollama 설치 → 설치 스크립트 → 실행 스크립트).
- 설치 없이 데모 주소(https://jeju-agent-junhees-projects-5f5f2302.vercel.app)에서도 같은 계정으로 로그인해 쓸 수 있다. 데모의 로컬 모델은 개발자 PC의 Ollama에 연결돼 있어, 로그인하지 않은 여러 단계 질문은 센터 PC보다 느릴 수 있다.
- 질문과 답, 동네 비교, 통계 기법, 보고서 인쇄, 상세 분석(로컬 모델 `qwen2.5:7b`)은 로그인 없이 쓴다.
- **질문하기 전에 아래 계정으로 로그인한다.** Claude 기능은 로그인한 요청에만 쓴다. 로그인하면 여러 단계 질문(예: '노형동 카페 매출 흐름을 보고 연동과 비교해줘')에서 Claude(Sonnet)가 단계마다 도구를 골라 문항당 평균 13초에 답한다. 로그인하지 않으면 로컬 7B가 골라 평균 50초 걸린다(판정 60문항, 2026-11-18 측정). 답 내용은 두 경우 같다(43/60).
- 상세 분석에서는 로그인한 뒤 [Claude로 분석]을 누른 요청에 Claude를 쓴다. 이때 ZIP의 `.env`에 든 평가용 키를 쓴다. 평가용 키에는 사용 한도가 걸려 있고, 평가가 끝나면 폐기한다.

| 항목 | 값 |
|---|---|
| 아이디 | `<제출 ZIP에서 채움>` |
| 비밀번호 | `<제출 ZIP에서 채움>` |
| 사용 기간 | 평가 기간(2026-11-23 ~ 2026-11-27) |

## 2. 로그인 방법
1. 화면 왼쪽 사이드바 맨 위의 [로그인]을 누른다.
2. 아이디와 비밀번호를 넣는다.
3. 질문 화면에서 그대로 질문한다. 여러 단계 질문에는 Claude가 자동으로 쓰인다.
4. 사이드바의 '상세 분석'을 열고, 분석을 문장으로 요청한 뒤 [Claude로 분석]을 누른다. 예: `43개 동네를 방문·매출·가게 수로 군집분석 해줘`

## 3. 제한
- 상세 분석은 하루 요청 수에 상한이 있다(기본 50건, `JEJU_EXPERT_DAILY`).
- 로그인은 한 IP에서 10분에 5번까지 틀릴 수 있다. 넘으면 10분 뒤 다시 시도한다.
- Claude 키에는 사용 한도가 걸려 있다. 한도에 닿으면 [Claude로 분석]이 꺼지고, 여러 단계 질문은 로컬 7B로 돌아간다. 질문과 답·로컬 모델 상세 분석은 그대로 쓸 수 있다.
