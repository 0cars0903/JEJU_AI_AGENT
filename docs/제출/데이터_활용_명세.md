# 데이터 활용 명세

제주빅데이터센터 빅데이터 분석·컨설팅 지원 보조 Agent가 쓰는 자료의 출처, 전처리, 이용조건을 적는다.
표 파일과 숫자는 `notebooks/01_데이터_확인.ipynb`에서 직접 확인할 수 있다.

- 기준일: 2026-11-13
- 앱이 읽는 자료: `data/tables/`의 표 17개(제출본 포함, 약 6.1MB). 실행 중에는 외부 API를 부르지 않는다.
- 원자료: 크기와 재배포 조건 때문에 제출본에 넣지 않는다. 다시 받는 방법은 README '데이터 갱신'에 있다.

## 3. 전처리

### 3.1 공통
- 동네 단위는 제주 행정동 43곳으로 맞춘다.
  - 법정동 자료(746)는 793 상가 수 비율로 행정동에 나눈다.
  - 정류소(743)는 이름으로 동네에 잇는다. 2024년 승차의 99.63%가 동네에 연결됐다.
- 유동인구(583)는 API 문서에 집계 단위 설명이 없어 사람 수가 아닌 지수로만 쓴다.
- 원본 파일은 `data/raw/`에 그대로 두고 고치지 않는다. 문자 인코딩(CP949)과 칸 나눔 오류는 읽는 코드에서 처리한다.

### 3.2 원자료를 그대로 쓰면 값이 달라지는 경우

| 사례 | 그대로 쓰면 | 왜 문제인가 | 처리 |
|---|---|---|---|
| 정방동 버스 이용 증감(2023→2024) | +95.9% | 이름이 바뀐 정류소를 새 정류소로 센다 | 이전·이후 이름을 한 정류소로 합침 → +9.6% |
| 노형동 카페 개업(2026년) | 17곳/년 | 2026-11-07까지만 집계되어 다른 해보다 적게 보인다 | '2026년(11월 7일까지) 17곳'으로 표시 |
| 노형동·연동 방문 차이 | 일별 검정 p 2.0e-58 | 하루 값이 전날과 비슷해(1일 자기상관 0.877) 차이가 실제보다 확실하게 보인다 | 주 평균 53주 짝 검정 p 2.5e-10 |
| 카페 카드 매출 | 음식점업 전체 값 | 카드 자료의 업종이 대분류 5개뿐이다 | '음식점업 전체(카페 포함)' 안내 문구 |

### 3.3 교차 대조(제주관광공사 카드 ↔ 데이터허브 746)
- 겹치는 기간: 2020-01~2021-05.
- 기준: 전월 대비 방향 일치 0.75 이상, 전년 대비 방향 일치 0.8 이상.
- 결과: 6개 계열 가운데 5개가 통과했다. 숙박업·도민 계열은 전년 대비 방향 일치가 2/5로 기준에 못 미쳤다.
- 앱은 매출 답에 제주관광공사 자료를 쓰고, 746은 이 대조에만 쓴다.

## 4. 재배포와 제출본 구성
- 제출본에는 가공한 표(`data/tables/`)와 그 표를 만드는 코드만 넣는다. 원자료 파일은 넣지 않는다.
- 데이터 API 키(`JEJU_DATAHUB_KEY`, `DATA_ASOS_API_KEY`)는 제출물에 넣지 않고, README에 발급 방법만 적는다.
- 답 화면과 보고서 PDF에는 자료마다 출처와 기준 시점을 함께 표시한다.

## 5. 센터 자료
- 센터 자료 73종의 목록과 조회 조건은 `data/catalog.json`에 있다. 화면의 '자료 요청' 카드가 필요한 센터 자료와 조회 조건을 안내한다.
- 센터 PC에서 조회한 결과 CSV를 '센터 자료 넣기'로 넣으면 그 자료로 다시 계산한다. 지금 읽을 수 있는 형식은 카드 매출 1-07·1-08이다.
- 센터 원자료는 제출본에 들어 있지 않다.
